SHORT Main memory bandwidth and double-precision FLOPs

EVENTSET
PMC0  INST_RETIRED
PMC1  CPU_CYCLES
PMC2  FP_DP_FIXED_OPS_SPEC
PMC3  FP_DP_SCALE_OPS_SPEC
UCF0  MEM_BYTES_RD_CPU_FROM_CMEM
UCF1  MEM_BYTES_WR_CPU_TO_CMEM

METRICS
Runtime (RDTSC) [s]    time
Clock [MHz]    1.E-06*PMC1/time
CPI    PMC1/PMC0
FP rate [MFLOP/s]    1.0E-06*(PMC2+PMC3)/time
SVE FP rate [MFLOP/s]    1.0E-06*(PMC3)/time
Scalar/NEON FP rate [MFLOP/s]    1.0E-06*(PMC2)/time
SVE ratio    100*(PMC3)/(PMC2+PMC3)
Memory read bandwidth [MBytes/s]    1.0E-06*(UCF0)*32.0/time
Memory read data volume [GBytes]    1.0E-09*(UCF0)*32.0
Memory write bandwidth [MBytes/s]    1.0E-06*(UCF1)/time
Memory write data volume [GBytes]    1.0E-09*UCF1
Memory bandwidth [MBytes/s]    1.0E-06*(UCF0+UCF1)/time
Memory data volume [GBytes]    1.0E-09*(UCF0+UCF1)


LONG
Formulas:
FP rate [MFLOP/s] = 1E-06*(FP_DP_FIXED_OPS_SPEC+FP_DP_SCALE_OPS_SPEC)/time
SVE FP rate [MFLOP/s] = 1E-06*FP_DP_SCALE_OPS_SPEC/time
Scalar/NEON FP rate [MFLOPS/s] = 1E-06*FP_DP_SCALE_OPS_SPEC/time
SVE ratio = 100*FP_DP_SCALE_OPS_SPEC/(FP_DP_FIXED_OPS_SPEC+FP_DP_SCALE_OPS_SPEC)
Memory read bandwidth [MBytes/s] = 1.0E-06*MEM_BYTES_RD_CPU_FROM_CMEM*32.0/runtime
Memory read data volume [GBytes] = 1.0E-09*MEM_BYTES_RD_CPU_FROM_CMEM*32.0
Memory write bandwidth [MBytes/s] = 1.0E-06*MEM_BYTES_WR_CPU_TO_CMEM/runtime
Memory write data volume [GBytes] = 1.0E-09*MEM_BYTES_WR_CPU_TO_CMEM
Memory bandwidth [MBytes/s] = 1.0E-06*(MEM_BYTES_RD_CPU_FROM_CMEM+MEM_BYTES_WR_CPU_TO_CMEM)/runtime
Memory data volume [GBytes] = 1.0E-09*(MEM_BYTES_RD_CPU_FROM_CMEM+MEM_BYTES_WR_CPU_TO_CMEM)
-
Profiling group to measure memory bandwidth for CPU memory and
FP rate in double-precision for scalar and SVE vector operations
